# Plans and Execution History

## Purpose

This section collects the DecisionGraph BEAM master plan and the phase-by-phase execution records in one durable place.

These files started as root-level transformation notes while the platform was being built.
After `v0.1.0`, they were moved under `docs/plans/` so the repository root stays focused on the product itself.
